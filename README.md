# 私人云盘 - 本地轻量级网盘
（不用装软件、不用服务器，打开就能用）

## 👀 先看：这个云盘能干嘛？
- 自己注册账号，密码只有你自己知道
- 登录后可以上传文件（照片、文档、小视频都可以）
- 上传的文件存在你自己的电脑里，不会传到网上
- 关掉页面再打开，不用重新登录
- 不想用了可以退出登录，文件也不会丢

## 📝 超简单使用步骤（一步都不用多）
### 第一步：打开云盘
点击下面的链接就能直接打开：
[点击这里打开私人云盘](home/index.html)
（如果点不开，就自己找到「home」文件夹，双击里面的「index.html」文件）

### 第二步：注册账号
1. 打开后先点「去注册」
2. 随便填一个你想用来登录的「用户名」（比如：我的云盘）
3. 填一个「密码」（不用记复杂的，自己能记住就行）
4. 点「注册」，提示“注册成功”就可以了

### 第三步：登录使用
1. 注册后会自动回到登录页，输入你刚填的用户名和密码
2. 点「登录」，就能进到云盘主界面
3. 上传文件：点击“点击或拖拽上传”的区域，选你要存的文件就行
4. 删文件：文件右边有红色的「删除」按钮，点一下确认就删了
5. 退出登录：不想用了点右上角「退出登录」就行

### 第四步：下次用的时候
直接打开链接/文件，不用重新登录，直接就能用（除非你点了退出）

## ❓ 常见问题（看不懂就看这里）
1. 点链接没反应？
   → 检查「home」文件夹和这个 README 文件是不是在同一个文件夹里
   → 直接双击「home」里的「index.html」最稳妥

2. 注册/登录按钮点不动？
   → 确保「home」文件夹里有「css」和「js」两个文件夹，里面的文件都在

3. 上传的文件在哪？
   → 存在你打开这个页面的浏览器里，换浏览器/电脑就看不到了
   → 想在别的电脑用，把整个文件夹复制过去就行

4. 忘记密码怎么办？
   → 重新注册一个新账号就行（旧账号的文件还在原来的浏览器里）

## 💡 小提示
- 适合存小文件（照片、文档），太大的文件（比如几个G的视频）不建议
- 只要不删这个文件夹，你的文件和账号就一直都在
- 不用连网也能用（因为所有东西都存在你自己的电脑里）
